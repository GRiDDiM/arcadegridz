# 8-BIT ROCKETSHIP (2008)
BDC's chiptune album for the ArcadeGridz app music player.
Served from https://arcadegridz.com/music/8bit-rocketship/ (album.json = track list + L/R peak meters, cover.png = 2008 CD label art).
Original 2008 MP3s, stream-copied with new tags (no re-encode). stingers/ = the eight short TRIP clips from the same CD, for game use.
build.py rebuilds from the original folder.
